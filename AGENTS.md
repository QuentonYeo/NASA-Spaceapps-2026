# Feature documentation

Whenever a feature changes, update its HTML document in `features/` in the same set of changes. Keep the documented behavior, eligibility rules, design reasoning, and known limitations in sync with the implementation. If a feature has no document yet, create one in that folder.

Before committing a feature change, review the staged diff and include the corresponding documentation update in the same commit.

The Aligned Blink feature is documented in `features/aligned-blink.html`.
