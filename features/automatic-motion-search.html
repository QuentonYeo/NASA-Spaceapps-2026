Automatic motion search

In Explore for movement, enter RA, Dec and field of view, or pick a suggested field, then select Start. The viewer downloads the requested field through successive batches. In either Explore or a known-object preset, use the Auto observation panel directly under the frame timeline. When loading finishes, including when frames were preloaded, select Start auto observation to scan retained FITS data and rank candidate tracks. Select a candidate to open its supporting exposures in Aligned Blink and filter the timeline to those exposures. Select Show all frames to return to the full timeline. Use Run auto observation again to repeat the scan on the same retained frames.

How the first pass works

  1. Finish loading the field before analyzing it. The analysis reads all available retained FITS frames without another archive download. Downloads continue in batches, and the viewer shows analysis progress separately.
  2. On the calibrated native FITS image, estimate local background with a median filter. Find up to 24 strong local peaks per frame, using valid-pixel masks, robust noise estimates and the variance plane when available. Require an unmasked peak and at least 15 usable pixels in its 5 Ã— 5 neighborhood. Project each measured peak onto the aligned sky grid.
  3. Compare exposures from the same detector and release. Reject peaks coincident with peaks in comparable frames within the search time window. Consider triples with at least 30 minutes between measurements and no more than two days across the track. Link three positions at different times on a roughly straight track. Require movement of at least three native pixels, an intermediate position within 1.6 pixels of the trial track and frame-center wavelengths within 15% of one another. Rank by the weakest detectionâ€™s peak signal-to-noise and the intermediate-position residual. Tracks sharing a detection or passing within four pixels in two supporting frames are deduplicated across the downloaded sequence. The candidate list appears after analysis finishes.

For fixed-position brightness changes, open Brightness over time in the RW Aurigae and R Draconis presets. A zero-track motion result does not measure stellar variability.

Analyze a moving candidate

In Verify, choose an aperture radius and select Measure candidate to measure the marked position in each supporting native FITS frame. A dashed violet circle shows the aperture radius on the aligned image. Clicking the measured marker jumps to this panel. If a science cutout was evicted from memory or the saved search cache, the backend reloads that exposure from the archive on demand. The backend uses fractional circular aperture photometry with a clipped local-median background annulus. Results include quick-look flux in mJy, coverage, flags, local wavelength and bandwidth when available, and approximate statistical uncertainty when VARIANCE is usable. Flux-versus-time and sparse flux-versus-wavelength plots and a CSV table are provided.

This per-exposure moving-position measurement is distinct from the stationary 102-channel mosaic spectrum. Sampling is sparse and may cover only one band; uncertainties omit correlated-noise and calibration systematics. The measurement is not PSF matched or a contiguous spectrum. Frames lacking retained science or adequate coverage can be unavailable or partial.

Interpret the results

Exposure discovery calls IRSAâ€™s public SIA search directly. A lookup error means the archive search failed before analysis. Use Start again once the archive is available.

This baseline uses numerical image processing and deterministic ranking. It does not use an LLM or a trained model. Scores rank candidates within the analyzed data and are not probabilities of discovery. A search without tracks only describes the exposures and thresholds actually tested. If there is no eligible triple, the viewer reports insufficient comparable data. The analysis requires usable sky mapping and local wavelength metadata, so IMAGE-only cutouts cannot be analyzed.

Current limitations include coarse wavelength matching at the field center, peak-pixel astrometry, and no known-object cross-match or shift-and-stack. Only frames with retained FITS data and aligned previews can be scanned. The viewer reports when some downloaded frames lack those inputs. New checkpoints save retained FITS data along with previews and completed candidate lists. The active search and disk cache both have size limits. For older saved searches missing FITS inputs, choose Reload field for analysis once to retrieve the missing data. A result from only a subset of frames can miss a real mover. Blends, artifacts, or unrelated spots can still form false tracks. Faint, slow, or curved tracks may be missed. How astronomers check for motion

Measurement excludes invalid image values before summing. Aperture coverage includes missing area outside the cutout, so edge clipping lowers coverage. Archive photometry requests allow up to five minutes; a timeout is reported separately from a connection failure.

Automatic measurements

After detection finishes, every candidate is queued for background measurement using a 2.5 native-pixel aperture. The list shows queued, running, completed or failed status for each candidate. Detection results remain available while measurements run sequentially. Selecting a candidate opens its own plots and table; changing the aperture radius uses a manual measurement. The default results are saved with the search checkpoint and reused when opened again. Interrupted queued/running work resumes on reopening the search. Failed measurements can be retried manually. If no usable positions can be measured, the candidate reports failure and retains unavailable rows.

Background processing may reload missing archive cutouts. Results remain quick-look measurements with the same masking, coverage and uncertainty limitations. The browser polls until all candidates finish; scientific reference validation remains pending.

Automatic candidate measurements execute on a separate single-worker queue, so they do not occupy the two search workers. Partly unavailable default measurements can be retried instead of permanently returning the cached incomplete result. Measurement state is checkpointed at the end of the automatic run rather than rewriting all preview images for each candidate state transition; interrupted runs may repeat uncheckpointed measurements.

Run auto observation again, available in the timeline panel for Explore and validation presets, recomputes tracks and queues fresh default candidate measurements. The motion status can become completed before that separate measurement queue finishes; the viewer continues polling queued and running measurement entries.
