Gaia reference stars

In Aligned Blink, enable Gaia reference stars to overlay expected Gaia DR3 source positions. A group of visible sources shifting together can indicate a residual alignment error.

Catalogue and projection

The backend queries the Gaia ESA Archive through TAP on demand using the active search center and a cone radius of field of view divided by √2 plus 0.03°. It keeps up to 150 optically brightest catalogue entries in the retained backend job. The same catalogue serves all frames in the sequence, independently of SPHEREx archive requests.

The viewer uses Gaia’s reference epoch and available proper-motion components to estimate each source position at the SPHEREx observation time. It projects each position onto the north-up 6.15 arcsec/pixel aligned grid and filters markers outside the image or on transparent pixels. Marker positions follow the preview at each display size.

Interpretation

Markers are catalogue predictions. Gaia observes optical light, so marked sources may be faint or invisible in SPHEREx infrared frames, and infrared sources can lack Gaia counterparts. The overlay uses linear proper motion and omits parallax and perspective acceleration. Use isolated stars visible across the selected frames to assess alignment.
