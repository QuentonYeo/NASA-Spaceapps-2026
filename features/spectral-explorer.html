Using the viewer

  1. Choose Explore for movement from Home. Enter RA, Dec and FOV, optionally select a detector, then choose Start. The first batch loads on demand; use Load next batch for more observations.
  2. Click a location or drag a circular aperture on the native image. Adjust the aperture and background radii, then choose Update sky region.
  3. Read the background-subtracted spectrum in mJy. Reference annotations mark approximate spectral-feature positions; they do not identify compounds.
  4. Browse observations without changing the sky selection. A blue marker shows the displayed frame’s wavelength at the query centre. Select a spectral channel to find loaded observations within its wavelength edges.

On narrow screens, use Image to choose a region, Spectrum to inspect the fixed-sky 102-channel result, and Measurements to view its channel table. Selecting a region or updating its radii opens Spectrum automatically. If Verify is active, the panel links to the moving-candidate measurements; moving-target analysis links back here. These are separate measurements with separate positions.

The outline remains anchored in sky coordinates when native images change. Dashed rings show the background annulus. An uncached frame briefly reports positioning; missing WCS produces an explicit error. Portions outside the cutout are clipped.

In Explore, click a location or drag a circular aperture to select a stationary sky region in a loaded native FOV image. The reference must retain its FITS coordinates. Cached larger cutouts are cropped with matching science planes and shifted primary/alternate reference pixels, keeping selection and preview coordinates consistent. New disk checkpoints restore retained science FITS alongside the previews. Start in Explore can reload an older preview-only search before region selection. The server resolves the aperture and annulus to ICRS coordinates immediately, so native overlays follow frame changes without waiting for the remote spectrum.

The default annulus spans two to three times the aperture radius. Both radii are editable in the original reference image pixels; resolved angular sizes are displayed. These settings need not equal the notebook’s example of 5/40/60 cube pixels. Reproducing a value requires the same position, radii and quality masks.

All 102 numbered slots remain available in Channel coverage, grouped into six detectors. Wavelength centres and edges come from SPECTRAL_CHANNELS with calibrated units. DR1 slots 51 and 52 are intentionally blank. Missing channels remain null and disabled; negative accepted flux is retained. The slider skips unavailable measurements.

Spectrum data

The 102-channel spectrum reads a separate DR1 HiPS FITS mosaic. It reports a fractional aperture sum minus a sigma-clipped local background, in mJy. The native observations provide sky selection and image navigation; their observation times and wavelength markers remain available in the viewer.

The mosaic combines observations across epochs and does not provide flux uncertainty. There is one spectrum product in this app.

Channel-to-frame navigation uses wavelength at the query centre. Wavelength varies spatially, so these links are navigation aids rather than a guarantee of identical bandpass or flux.

Photometry and units

  1. Find the order-5 HEALPix tiles intersecting the aperture and background annulus.
  2. Convert the angular radii to pixel-plane circles using the local WCS pixel solid angle, including HPX projection geometry.
  3. Sum the aperture using Photutils exact fractional pixel weights.
  4. Estimate the background from annulus pixel centres, with 3σ clipping for up to 10 iterations.
  5. Subtract the background mean times the accepted aperture area, then convert MJy/sr to mJy using the local pixel solid angle.

This matches the IRSA HiPS tutorial method. The app additionally applies finite-data, NHITS and flag masks, scales the subtraction to accepted area, and pools annulus samples across tile seams. Those extensions can change values relative to an unmasked notebook run.

HiPS is itself a mosaic cube. Its position-indexed tiles support bounded region reads; this choice does not imply superior photometry to other mosaic products. Pixel-plane circles follow the tutorial, while the displayed sky-circle rings approximate them on distorted grids.

Quality and interpretation

Finite IMAGE values, positive NHITS and header-defined SOURCE/FULLSAMPLE flags are accepted in source and background. Other flags are rejected. Tile ownership prevents duplicate contributions. An empty accepted aperture or background annulus makes the channel unavailable rather than returning an unsubtracted source or an invented zero.

Aperture coverage measures accepted fractional solid angle. Background coverage approximates accepted area after clipping. Partial flux remains visible with an explicit reason; there is no correction for missing source area. The cube already subtracts zodiacal light; the annulus estimates additional local background.

The plot always shows background-subtracted mJy flux. One Composition references switch enables or disables all hydrogen, PAH, CO and ice annotations together. It is enabled by default and changes only the overlays, without modifying flux, the observation wavelength marker or extraction requests. Cited reference positions remain educational markers. They are not fitted band centres or chemical detections.

The cube has no variance extension, so uncertainty and significance are unavailable. Combined epochs, striping, blending, unmatched PSFs and coarse pixels limit interpretation. Moving and variable targets are unsupported; an exoplanet-host aperture includes unresolved system light. No PSF or aperture correction is applied. Use the official IRSA spectrophotometry service for scientific source measurements.

Layout and performance

In Explore, the RA, Dec, FOV and detector controls always appear first in the control panel and stay expanded when observations load or the selection changes. Region controls follow below, with no top divider. The spectrum panel stays open with a bounded height and internal scrolling. Radius controls keep their space before selection, and asynchronous extraction does not expand the panel. Channel coverage is expandable. Composition references use one enabled-by-default on/off switch for all annotations; there are no individual reference controls. The quality policy and limitations are documented below. Mobile tabs preserve the selection; the spectrum remains available below the image.

The plot shows background-subtracted mJy flux. Navigating frames or channels does not restart mosaic extraction. Native overlays are cached by sequence, frame and sky aperture, with only adjacent overlays prefetched.

Saved searches reconnect after refresh and resume downloads. Older preview-only checkpoints cannot supply native selection coordinates. Start in Explore reloads a search when all restored images lack retained science. Existing in-memory cutout coverage is reused where available.

Channel measurements remain available separately below the viewer. Obsolete mosaic requests cannot publish results for another selection.

Acquisition and cache

POST /api/frames/{sequence}/fingerprints starts or reuses an analysis and immediately returns its resolved sky region. GET /api/frames/{sequence}/fingerprints/{analysis} polls loading, ready or failed status. Requests are scoped to an existing sequence. There is no channel-image endpoint or preview-generation path.

Validated HTTP 206 byte ranges read bounded IMAGE, NHITS and FLAGS row strips across the aperture and annulus. Up to twelve parallel reads batch rows per channel. Reads reject unbounded/full-file responses, retry transient failures, and enforce a two-minute deadline per tile and 2 MiB per-range cap. Background annuli can require substantially more data than an aperture-only measurement.

The persistent range cache defaults to 1 GiB with oldest-range eviction; complete local tiles remain reusable. Analyses include release, sequence, region, annulus and processing version in their identity. Finished analyses expire after 30 minutes, with at most twelve retained and four pending/running; two workers extract photometry. Shutdown drains active workers and cancels queued work.

Frame and channel navigation do not restart extraction. Native WCS projections are cached separately, up to 128 entries, with adjacent overlays prefetched. No notebook is imported at runtime. Extraction and cache implementation

Native images and aligned blink

The Home, Validate and Explore routes remain separate. Validate keeps its prepared examples, preferred comparison pairs, Gaia reference stars and optional Arosa trajectory. Spectrum controls and their mobile tabs appear only in Explore; the guided moving-object workflow does not start a stationary mosaic extraction.

Region drawing and coordinate conversion use the native IMAGE WCS. Aligned Blink uses a separate north-up display grid, so native overlays and drawing are hidden there. Selecting a linked observation returns to its native image. Blink reference selection, add/remove, playback and shared contrast remain independent.

Exports, validation and limits

Frontend regressions cover channel navigation, projection reuse and scoping, obsolete requests, and overlays before mosaic completion. Backend tests cover mosaic photometry, FITS preservation, caching, wavelength WCS and missing data. These checks do not establish live scientific calibration or browser layout accuracy.

Discovery covers the query centre, not every source within the FOV. Missing or unretained exposures stay unavailable. Combined epochs, blending, coarse mosaic pixels, unmatched PSFs and uncertain backgrounds limit interpretation. No abundance, chemical detection, moving-target spectrum or detection significance is inferred.
