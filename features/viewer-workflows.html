Viewer workflows

The home page offers two ways to start a SPHEREx session. The known-object list shows each preset’s RA, Dec, and field of view in degrees. Choose a known object directly from the list to start its validation sequence, or enter coordinates in New observation and click Start to begin loading the field in Explore.

The home and observation views use a dark theme with native system typography, charcoal panels and blue controls. The full-width home hero uses the Hubble image of M101 and aligns its headline with the first workflow card’s heading.

Available SPHEREx data

Home lists the Wide Survey spectral image collections supported for Explore. New field searches include DR1 by default. Select Include QR3 on Home or in Explore’s Observation settings to search both collections. A search fetches matching field cutouts on demand. Newly indexed QR3 exposures become searchable without changing the app. Known-object validation keeps its existing preset searches, and the region spectrum still uses the DR1 All-Sky Cube. IRSA release notes

The frame limit still applies to the combined search. Use a detector filter or search DR1 alone if the field returns too many frames. Aligned Blink compares frames within a single release. To support a future release with compatible spectral images, add its collection to the frame query allowlist and the release controls, then verify archive discovery and FITS cutouts for the collection.

Validate a known object

Select Vesta, Arosa, M101 or Barnard’s Star on Home to open the validation view. Return to Home to switch objects. The active object’s name appears at the top of the validation view. Each preset shows its field coordinates and what to inspect. For these four curated examples, the backend filters discovery by DR1 exposure ID before scheduling cutouts. The viewer opens in Aligned Blink, selects the documented frames as they arrive and enables Gaia reference stars. Vesta and Arosa have amber trajectory overlays that can be toggled off. If the documented comparison is incomplete, the viewer shows available aligned frames and explains the fallback. If the archive request is partial or fails, select Retry validation in Download status.

Epsilon Indi B (331.117°, −56.808°, 0.08°), WISE 0855−0714 (133.795129°, −7.245147°, 0.12°), RW Aurigae (76.956542°, +30.401417°, 0.06°), and R Draconis (248.167611°, +66.754979°, 0.06°) use archive field searches. They open in Aligned Blink with the available exposures and support manual frame selection. These presets have no verified exposure pair or target overlay. Compare the brown-dwarf fields across widely spaced dates. For the variable stars, compare brightness at the same position in similar-wavelength exposures with locked contrast. Barnard’s Star retains its existing curated exposures and field. RW Aurigae and R Draconis also offer Brightness over time from retained FITS exposures.

Auto observation appears beneath the title in Explore and Validate. Brightness over time appears there for the two variable-star presets in Validate. On narrow screens, Explore shows Auto observation on the Image tab. Its button becomes available when loading has finished and there are retained FITS frames with aligned previews. It also works with preloaded sequences and can rerun a completed analysis.

A local demo can set VITE_PRELOADED_VALIDATION_SEQUENCES in frontend/.env.local to a JSON map from preset IDs to completed backend sequence IDs. Clicking a configured preset opens its saved frames. If the sequence expires, the viewer submits the preset search again.

Vesta is selected by default and plays three verified D6 exposures in time order. Arosa demonstrates motion across two checked positions, M101 serves as a stationary alignment control, and Barnard’s Star is a subtle-motion exercise. The exact Barnard pair is a metadata-verified example with an unmeasured centroid shift. See the validation guide for dates, provenance and interpretation.

Observation view

When the viewer has no frames, the planet icon marks the empty image area. Start an observation from the field form or choose a known object from Home.

In both views, download progress appears above the viewer. The frame timeline and playback controls sit directly above the image. A scrollable metadata table below the image follows the timeline, highlights the current exposure, and marks the frames selected for blink playback. Previous and Next follow the order of the visible timeline. The timeline lists every available frame, even when the separate Play blink control loops a smaller set. Choosing an Auto observation candidate filters the timeline to its supporting frames. Select Show all frames to restore the field timeline. Display settings and field controls sit below metadata. Explore’s native region and spectrum workflows remain available.

Explore for movement

In Browse observations, click a source or drag outward from its center on a native frame, then name the selected region and choose Save as known object below the image. Saving uses coordinates from the retained FITS exposure and can finish while the region spectrum loads. The object appears in the Home list on the same browser. Opening it starts a new search around the saved circle, using the original detector and supported release when available. The viewer prefers the source exposure for Aligned Blink and draws the saved circle on the aligned frames. A saved object is a personal sky region and does not represent a catalogue identification. The original frame may be unavailable on a later search.

Enter RA, Dec and field of view, optionally choose a detector, or use a curated starting field. Suggestions explain why a field is useful for comparison. The viewer downloads the field in successive batches. When downloads finish, Start auto observation scans the retained FITS frames and ranks candidate tracks. Automatic motion search Selecting a detector restricts the search before image downloads. Changing fields still uses the existing FITS cutout cache where coverage allows.

Explore also includes the region spectrum. In native Browse observations, click or drag a sky aperture to load the 102-channel mosaic spectrum. This stationary-sky tool remains separate from Validate, which retains the guided blink, Gaia and Arosa controls. FOV controls stay first; the spectrum does not start from image navigation alone.

Automatic field ranking and manual motion measurements are future work. The current suggestions describe known fields and do not indicate a detection.
